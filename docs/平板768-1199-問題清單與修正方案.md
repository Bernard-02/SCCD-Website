## A. 確定 bug（建議修）

### A-1. create 頁在寬度剛好 768 整頁空白 ⭐最嚴重
- **實測**：768×1024 → canvas 0×0、`.mobile-logo-container` 0×0，畫面只剩 header logo。769/810 寬則正常出桌面版。
- **根因**：JS 與 CSS 的手機 gate 差一像素——
  - `generate-app/js/utils.js:75`：`isMobileMode = matchMedia('(max-width: 768px)')` → **768 算手機**
  - `css/components/create.css:1079`：`@media (max-width: 767px)` → **768 算桌面**
  - 寬度 = 768 時：JS 建手機版（canvas 尺寸量 `.mobile-logo-container`），CSS 卻沒開手機版容器 → 量到 0×0 → 空白。
- **真機命中**：iPad mini／iPad 9.7 直放 CSS 寬就是 768。
- **修法**：`utils.js:75` 改 `(max-width: 767px)`，對齊全站 isMobile（<768）慣例。一行修。
- ⚠️ 但要跟 A-2 一起決策：768 改回「桌面」後，會落進 A-2 的擠壞桌面版。

### A-2. create 頁 769–約1000 直放：桌面版左右被切
- **實測**：810×1080（iPad 10.2 直放）「TYPE AND ENTER」佔位字出血左緣（只剩 YPE/ND/ITER）、右側圖形出右緣。769 同。1180×820 正常。
- **根因**：create 桌面版面（左字右圖＋底部控制列）沒有窄直放的適配層。
- **方向（需 user 拍板）**：
  - 甲案：把 create 的手機 gate 擴大成「直放平板也走手機版」——JS＋CSS 同步改成 `(max-width: 1023px) and (orientation: portrait)` 之類（gate 必須 JS/CSS 同式，A-1 教訓）。手機版是直式流版，直放平板天生合身。
  - 乙案：桌面版加 769–1023 壓縮層（字級/間距縮）。工程量大、收益低。
- 傾向甲案。

### A-3. footer 平板版第三顆 tab 被右緣切掉（768–約860 寬）
- **實測**：768 寬 footer「Affiliated Units 關聯單位」只露出約 100px 且**不可捲**；1180 正常。
- **根因**：`css/layout/footer.css:300` 平板塊（768–1199）`.footer-random > .footer-tabs` 是 absolute row、gap xl、`max-width:100%`，但**沒有** <768 手機塊那套配備（`footer.css:434-436` 的 `flex:0 0 auto`＋EN `max-width:10.5rem` cap＋base 段 overflow-x 可捲）。tabs 又排在右欄（左邊被 footer logo 佔掉 ~277px），窄平板塞不下三顆。
- **修法**：平板塊補 EN cap（比照 :435 的 10.5rem/6rem）＋ gap 在窄端縮（xl→md），必要時再補可捲。改後 `npm run build:css`。

### A-4. regulations 768 直放：hero 標題壓住內容欄
- **實測**：「REGULATIONS & POLICY 規章與政策」藍色標題 strip 直接蓋在右欄綠色 accordion 的「Academic Regulations 學則」區塊上（y~540-930 整段重疊）。donate/policy/accessibility 同版型但標題較短沒疊到（donate 768 已很貼近）。
- **根因**：legal 四頁在平板段仍吃桌面「左標題＋右內容欄」版型；`legal-title-random.js` 的 chip 迴避 padding 機制（memory：cap=欄寬−240）是為 <1600 桌面設計，768 時右欄只剩 ~240px、標題本身就寬到蓋進去。
- **修法方向**：768–1023 讓 legal 頁改走手機直式流（標題上、內容下），或 title max-width 在窄平板強制縮。需 user 拍板。

### A-5. regulations 768：accordion 內表格欄位被裁
- **實測**：綠色面板內規章表格「Course Sy…／Shil…／Offi…」右緣硬切。
- **根因**：同 A-4——右欄 ~240px 塞兩欄表格。若 A-4 採直式流版自然解掉；單獨修＝表格窄欄改上下堆疊。
