# 字級規範

字級系統定義在 `css/variables.css`，2026-08-05 由舊 `h1–h6 / p1–p2` 統一改名為 **7 階 `xs → 3xl`**（原 `h3`＝3.125rem 已移出文字刻度，抽成 `--icon-hero`）。套用管道有二：Tailwind `text-*` utility（`tailwind.config.js:54-62` 逐 key 映射到 `var()`）或 CSS 直接寫 `var(--font-size-*)`。

三 viewport：**桌面**（≥768px，`:root` 預設值）／**直向手機**（`@media (max-width:767px)` 覆寫，`variables.css:173-180`）／**矮橫向**（landscape gate，`landscape.css:27-39` 的 `:root` 把整套 token 壓成手機值）。

> 本檔為 2026-08-07 全站 sweep 產物，取代舊 `H1-H6/P1-P3` 命名版。`grep text-h1 / text-p1` 已全找不到。

## 1. 字級 token（7 階）數值

| token | 桌面 rem/px | 手機 ≤767 rem/px | 矮橫向 ≤500h | 定義 file:line |
|---|---|---|---|---|

| `2xl` | 6rem / **96px** | 2.5rem / 40px | 2.5rem / 40px | `variables.css:51` · `:175` · `landscape.css:29` |
| `xl` | 2rem / **32px** | 1.5rem / 24px | 1.5rem / 24px | `variables.css:52` · `:176` · `landscape.css:31` |
| `lg` | 1.4rem / **22.4px** | 1.2rem / 18px | 1.2rem / 18px | `variables.css:53` · `:177` · `landscape.css:32` |

## 3. 裸標籤預設字級（cascade 源頭）

沒帶 `text-*` class 的標籤靠 `@layer base` 的 `@apply` 拿字級（`css/base/typography.css`）。這是全站預設，六成頁面的內文/標題字級來自這裡。

| 元素 / 選擇器 | 來源 | token | 桌面 / 手機 | file:line |
|---|---|---|---|---|
| `html` | `@apply text-base` | — | **16px**（root，全站 rem 基準）| `typography.css:8` |
| `body` | *(無字級)* | — | 繼承 html 16px | `typography.css:13` |
| `h1` | `@apply text-3xl` | 3xl | 128 / 48px | `typography.css:20` |
| `h2` | `@apply text-2xl` | 2xl | 96 / 40px | `typography.css:24` |
| `h3` | `@apply text-xl` | xl | 32 / 24px（line-height 1.5）| `typography.css:28` |
| `h4` | `font-size: var(--font-size-xl)` | xl | 32 / 24px（line-height 1.1）| `typography.css:32` |
| `h5` | `@apply text-lg` | lg | 22.4 / 18px | `typography.css:38` |
| `h6` | `@apply text-md` | md | 20 / 16px | `typography.css:42` |
| `p` | `@apply text-s` | s | 16 / 16px | `typography.css:46` |
| `.nav-link` | `@apply text-md` | md | 20 / 16px | `navigation.css:10` |

- **`h3` 與 `h4` 同為 32px**，差別只在 line-height（h3 = 1.5、h4 = 1.1）。
- **桌面 nav 連結字級全靠 `.nav-link`**（`header.js` 不含任何 font-size）；`.submenu-link` 已於 2026-08-07 刪除（mega-menu 無下拉子選單）。
- **404 頁巨字**（`404.html:91,94` "ERROR/錯誤"）無專屬規則，純繼承 `<h1>` = 128 / 48px。

## 4. 使用量統計（2026-08-07 sweep）

### Tailwind `text-*` utility（`.html` + `.js`，已排除註解/selector 參照）

| token | 套用次數 | 主要位置 |
|---|---|---|
| `text-3xl` | 20 | 全為 `<h2>` section 錨點大標（about ×8 / alumni ×12）|
| `text-2xl` | 14 | Hero 標題（degree-show-detail / donate / policy / regulations）|
| `text-xl` | 16 | header 手機導覽 ×9 · DSD year/title · faculty／課程 slide-in 標題 |
| `text-lg` | 19 | about ×8 · activities list 主標 · timeline · index-marquee · alumni |
| `text-md` | **4**（最少）| about ×2 · faculty-slide-in ×2（Contact 小標 08-07 已移到 s）|
| `text-s` | **118**（主力，約六成）| 全站內文／按鈕／卡片欄位；activities-data-loader ×37 最多 |
| `text-xs` | 14 | lightbox-ref · degree-show ref · library sort-arrow · activities 國家 |

- **arbitrary 字級 `text-[14px]`：0 筆**；**responsive prefix `md:text-*`：0 筆**（字級的 RWD 全靠 token 的 media 覆寫，不靠 breakpoint prefix）。

### CSS `var(--font-size-*)`（`.css`，排除 output.css）

`3xl`=0 · `2xl`=0 · `xl`=5 · `lg`=5 · `md`=2 · `s`≈58 · `xs`≈17（2026-08-07 atlas 詳情字級收進 token 後 s/xs 各增數筆；另 2 筆 xs 帶 fallback）。`3xl/2xl` 只走 class 管道、CSS 內零引用。

## 5. /create（generate-app）獨立字級系統 ⚠️

`/create` 頁（內部代號 `generate`）跑 p5.js，字級**完全不吃主站 `text-*` token**，是獨立系統。`create.html` 本身無任何 `text-*` / `font-size`（純 SPA 容器）。

### 5a. Canvas logo 文字（p5 `textSize`）

畫的是使用者輸入字串拆成的單一字母，環繞成 SCCD logo。

| 情境 | 值 | file:line |
|---|---|---|
| 桌面固定 | **367.5** | `sketch.js:117,1664` · `draw-logo.js:88,223` · `save-download.js:77` |
| 手機縮放 | `(canvasWidth / 432) * 367.5 * 1.1` | `sketch.js:117,1630,1657` · `draw-logo.js:88` |
| 存檔 PNG | 367.5 + `scale(2)` → **等效 735px**（1080² 離屏）| `save-download.js:73,77,92` |

公式常數：**432** = 桌面基準 canvas 寬（`create.css:253`）、**367.5** = 桌面基準字級、**1.1** = 手機 +10%。
> `sketch.js:114-116` 註解 2026-08-07 已由「×0.96」更正為 `×1.1`（實際四處程式碼皆 ×1.1）。

### 5b. 桌面輸入框字級（依字數 4 階）
