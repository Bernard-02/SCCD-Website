最後更新：2026-07-17
========================================

這些設定後台 GUI 都改不了，必須進主機改環境變數檔（.env），
改完執行 `pm2 restart directus`（或你們啟動 Directus 的方式）重啟一次即生效。
.env 通常在 Directus 專案目錄下。DB 帳密也在同一個 .env 裡。


── 請求 1：限制可上傳的檔案類型（擋掉 HEIC / TIFF）──────────

原因：
  - iPhone 預設拍 HEIC、有些圖是 TIFF，這兩種格式瀏覽器都「無法顯示」，
    上傳後後台縮圖破圖、前台網站也看不到圖，而且不會報錯（很難查）。
  - 用白名單只放行網頁能正常顯示的格式，讓不合格的檔在上傳當下就被擋下。

在 .env 加這一行（若已有同名變數就改它的值）：

  FILES_MIME_TYPE_ALLOW_LIST="image/jpeg,image/png,image/gif,image/webp,image/svg+xml,application/pdf"

（＝允許 JPG / PNG / GIF / WEBP / SVG / PDF；HEIC、TIFF 會被擋）


── 請求 2：把圖片可處理的最大尺寸加大到 12000px ──────────────

原因：
  - Directus 預設圖片最大邊長上限是 6000px，超過的大圖在產生縮圖／預覽時
    會報「Input image exceeds pixel limit」而失敗。
  - 我們需要上傳到 12000px 的圖，所以把上限拉高。

在 .env 加這一行（若已有就改值）：

  ASSETS_TRANSFORM_IMAGE_MAX_DIMENSION=12000

備註給 IT：
  - 這個值是「單邊最大像素」，內部像素上限＝該值的平方（12000² ≈ 1.44 億像素）。
  - 若 12000px 的原圖檔案很大（超過預設上傳大小限制），可能還要一併調
    FILES_MAX_UPLOAD_SIZE（例：FILES_MAX_UPLOAD_SIZE="50mb"），視實際檔案大小而定。

  1. 重啟後 Directus 有正常起來（pm2 status / pm2 logs directus）
  2. 試上傳一張 HEIC → 應被拒絕
  3. 試上傳一張 >6000px 的大圖 → 後台應能正常產生縮圖
